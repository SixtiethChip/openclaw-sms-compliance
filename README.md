# OpenClaw SMS compliance site

A small static site for SMS opt-in information, a privacy policy, and terms and conditions.

The site uses HTML and CSS only. It has no analytics, tracking pixels, cookies, advertising, lead-generation form, JavaScript, or remotely loaded assets.

## Pages

- `/` — SMS opt-in
- `/privacy/` — Privacy Policy
- `/terms/` — Terms & Conditions

The site is published with GitHub Pages.
